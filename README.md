# Machine Learning Algorithms Practice

This repository contains my hands-on practice of commonly used Machine Learning algorithms using Python and Scikit-learn.

The main goal of this repository is to understand how different ML algorithms work, implement them practically, and evaluate their performance using appropriate metrics.

## 📌 What I Practiced

### Supervised Learning

#### Regression
- Linear Regression
- Lasso Regression
- Decision Tree Regressor
- Support Vector Regression (SVR)

#### Classification
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Tree Classifier
- Random Forest
- Support Vector Classifier (SVC)
- Gradient Boosting
- XGBoost
- AdaBoost
- Heterogeneous Ensemble

### Unsupervised Learning

#### Clustering
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- DBSCAN for Anomaly Detection

#### Dimensionality Reduction
- Principal Component Analysis (PCA)

## 🔬 What I Practiced in Each Algorithm

For the algorithms, I worked through the typical Machine Learning workflow:

1. Load the dataset
2. Understand the data
3. Data preprocessing
4. Feature and target separation
5. Train-test split
6. Feature scaling where required
7. Model implementation
8. Model training
9. Prediction
10. Model evaluation
11. Hyperparameter tuning where applicable
12. Cross-validation where applicable

---

## 📊 Model Evaluation

Different evaluation metrics were used depending on the type of problem.

### Classification
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

### Regression
- MAE
- MSE
- RMSE
- R² Score

### Clustering
- Silhouette Score
- Cluster visualization
- Inertia / WCSS where applicable

---

## ⚙️ Hyperparameter Tuning

I also practiced improving model performance using techniques such as:

- GridSearchCV
- Cross-validation
- Hyperparameter selection
- Comparing different parameter values

For example, KNN was tested with different values of `n_neighbors` and evaluated using cross-validation.
